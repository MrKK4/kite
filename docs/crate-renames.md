# Crate rename map

All 100 workspace crates were renamed without name collisions. Rust import names
use the same mapping with underscores. User configuration and protocol names
remain compatible: `GROK_*`, `.grok/`, `groknight` / `grokday`, shell markers,
`x.ai/` methods, and HTTP headers retain their existing values.
